# Task Tracker

Task Tracker — это веб-приложение для управления задачами сотрудников. Система позволяет создавать, редактировать, просматривать и удалять задачи, а также отслеживать "важные задачи", зависимые от родительских.

## 📁 Структура проекта

dip/

├── config/ # Настройки Django

├── employees/ # Приложение для управления сотрудниками

├── tasks/ # Приложение для управления задачами

├── manage.py # Управляющий скрипт Django

├── requirements.txt # Список зависимостей

├── README.md # Документация проекта

└── .env # Переменные окружения


## ⚙️ Установка и запуск

1. Клонируйте репозиторий
2. Создайте виртуальное окружение и активируйте его

python -m venv venv
# Linux/macOS
source venv/bin/activate  
# Windows
Set-ExecutionPolicy Unrestricted -Scope Process

venv\Scripts\activate

3. Установите зависимости

pip install -r requirements.txt
4. Выполните миграции

python manage.py migrate
5. Создайте суперпользователя

python manage.py createsuperuser
6. Запустите сервер

python manage.py runserver

🔐 Аутентификация

Для доступа к защищённым эндпоинтам необходимо авторизоваться. Используется стандартная аутентификация Django. 
При необходимости можно подключить JWT или Session-авторизацию.

📚 API Эндпоинты
Все эндпоинты используют формат JSON и находятся по маршрутам, настроенным в urls.py.

# Задачи (/api/tasks/)

GET	/api/tasks/	Список всех задач

POST	/api/tasks/create/	Создание новой задачи

GET	/api/tasks/<id>/	Детали задачи по ID

PUT	/api/tasks/<id>/update/	Обновление задачи

DELETE	/api/tasks/<id>/delete/	Удаление задачи

GET	/api/tasks/important/	Получение списка важных задач

# Сотрудники (/api/employees/)

GET	/api/employees/	Список сотрудников

POST	/api/employees/create/	Создание нового сотрудника

GET	/api/employees/<id>/	Детали сотрудника по ID

PUT	/api/employees/<id>/update/	Обновление сотрудника

DELETE	/api/employees/<id>/delete/	Удаление сотрудника

GET DELETE	/api/employees/workload/	Список сотрудников и их задачи, отсортированный по количеству активных задач.

✅ Тесты

Для запуска тестов:

python manage.py test

Покрытие тестами:

-CRUD для задач

-Валидация задач (дата в прошлом, самоссылки, дедлайны подзадач)

-Работа списка важных задач и загруженности сотрудников

🧠 Особенности

Автоматическая проверка:

 -дедлайн задачи не в прошлом времени

 -дедлайн подзадачи не может быть позже дедлайна родительской

 -задача не может быть родительской сама себе

Список "важных задач"

Подбор свободных сотрудников к задачам на основе их текущей загруженности
